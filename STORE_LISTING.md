### Detailed description (English)

Save your ChatGPT conversations to your computer in one click, right from the browser side panel.

• Download the open chat, all chats, or just the ones you pick — with search and project/GPT/archive/date filters
• Only the messages you want: tick them one by one, Shift-click a range, "answers only" / "my prompts only"
• Formats: PDF (made in your browser — no server, no daily limit), Word (.docx), Markdown, ChatGPT-style HTML, TXT and JSON
• Attachments, images and files generated by ChatGPT, plus a gallery page of every image, including generated ones
• Math (LaTeX) renders properly in HTML/PDF and stays as $…$ in Markdown; Deep Research and web sources become footnotes; Canvas documents are kept
• Obsidian mode: YAML frontmatter, notes named after the chat, and saving straight into a folder you pick (your vault)
• Incremental backups: only chats that changed since the last backup
• Download from shared links (chatgpt.com/share/…)
• A "Download" button on the ChatGPT page and a right-click menu; Alt+Shift+D shortcut
• Live progress, cancel, automatic retries; light/dark theme; 10 languages

Privacy: No data is collected. The extension only runs on chatgpt.com and talks directly from your browser to chatgpt.com; there are no third-party servers, analytics or ads. PDFs are created entirely in your browser too.

Note: Not affiliated with OpenAI. It relies on ChatGPT's unofficial internal endpoints, so some features may stop working if they change. Expired or deleted attachments cannot be downloaded.

## Privacy practices tab

**Single purpose:**
Let users download and back up their ChatGPT conversations and attachments to their own device as files.

**Permission justification:**
- `sidePanel`: The extension's UI lives in the browser side panel.
- `scripting`: To inject the export code into the chatgpt.com tab when the user starts an export or opens a list.
- `storage`: To store the user's settings, the on-page button preference and, for incremental backups, conversation IDs with their last-updated times on the device. No conversation content is stored.
- `contextMenus`: To add "Download this chat" and "Open panel" to the right-click menu on chatgpt.com.
- Host permission `https://chatgpt.com/*` and content script (chatgpt.com only): the side panel stays open while the user switches tabs or chats, so `activeTab` is not enough. The content script only adds an optional small "Download" button to the chat header. No other site is accessed.
- Remote code: **None.** All code is in the package. KaTeX (MIT, `vendor/katex.min.js`) is bundled for math rendering; there is no `eval` and no remote script.

**Data usage disclosure:**
- Types of user data collected: **check none.** No data is sent to the developer or third parties; conversation content is processed only on the user's device.
- Confirm all three certifications (no selling, no unrelated use, no creditworthiness use).

## Test instructions for reviewers

1. Sign in to chatgpt.com and open a saved chat (the URL contains `/c/…`).
2. Click the extension icon to open the side panel.
3. Press **Download**. Progress appears in the panel and at the bottom right of the page, and the file downloads.
4. Other things to try:
   - "Choose chats" lists your chats.
   - "PDF" opens the print dialog.
   - A "Download" button also appears next to the chat's "Share" button.

## Icon and trademark risk

- The icon is the blue knot design in `icons/` (with a download arrow in the middle). The Store images in `store/` and the promo tile use the same icon. `tools/make-store-assets.py` builds them straight from `icons/icon512.png`.
- This icon resembles the OpenAI logo. The Chrome Web Store may treat icons that imitate another company's logo as misleading, so the submission could be rejected or the extension removed later. If that happens, replace the files in `icons/` and regenerate the Store images.
- The name follows the "… for ChatGPT" pattern. The side panel and the description both say the extension is not affiliated with OpenAI. If review asks for a name change, edit `extName` in `tools/locales.js` and `tools/locales/*.js`.
